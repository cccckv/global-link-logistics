# 交互与开发规则 (Project & Agent Rules)

## 1. 严格遵守讨论与提问模式 (Discussion & Q&A Mode)
- **禁止提前直接修改代码**：当用户提出“讨论”、“我们目前是在讨论”、“探讨一下”、“分析一下”或纯提问疑点时，**绝对不得主动修改任何源代码或执行写操作**。
- **职责范围**：在讨论/提问模式下，只能深入分析业务逻辑、梳理技术架构、比对数据字段并给出明确的对比方案与优缺点；
- **执行触发条件**：只有在用户明确确认并下达执行指令（例如“按照方案1执行”、“确认修改”、“提交修改”）后，方可对代码进行实际修改。

## 2. 真实数据与业务准则
- 始终以 `info/` 目录下的真实业务 Excel 表格为业务模型黄金准则。
- 散货（LCL）按体积算方、空运（AIR）按重量计费，整柜（FCL）按整柜包干总报价与干线硬成本链核算。
