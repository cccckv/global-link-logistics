## 📌 1. 业务概念与多币种背景

国际物流业务涉及跨境多环节协同，天然存在 **多币种结算 (RMB 人民币、PHP 比索、USD 美元)** 与 **细粒度成本项**：
- **人民币 (RMB / CNY)**：国内收发货人主运费结算、国内短驳拖车、国内港杂、出口报关费。
- **菲律宾比索 (PHP / Peso)**：目的港 THC（码头操作费）、超期堆存费、目的港派车小费、目的港现结运费。
- **美元 (USD)**：国际海运庄家订舱纯海运费 (Ocean Freight)。

## 📋 2. 整柜级费用明细（整柜成本与利润 - `ContainerFee`）

整柜费用归属于集装箱主表 (`ContainerMaster`)，通过 `model ContainerFee` 存储：

| 费用科目 (`feeSubject`) | 常见记录格式/示例 | 默认币种 | 费用归属与业务说明 |
| :--- | :--- | :--- | :--- |
| **订舱费 (`BOOKING_FEE`)** | `USD+235`, `USD+1100` | USD / CNY | 支付给船司/庄家的海运订舱纯海运费 |
| **港杂费 (`PORT_SURCHARGE`)** | `2300`, `2200` | CNY | 出口码头港口作业杂费 |
| **头程拖车费 (`TRUCKING_FEE`)**| `拖车3200`, `拖车5000` | CNY | 国内集装箱卡车短驳运输费 |
| **报关/产地证 (`CUSTOMS_FEE`)**| `8023`, `500` | CNY | 出口报关代理费及产地证(Form E)办理成本 |
| **清关费用 (`CLEARANCE_FEE`)** | 视渠道协议定 | CNY / PHP | 目的港清关代理申报与通关费用 |
| **THC超支/堆存 (`THC_OVERSTAY_FEE`)**| `thc 7859.2peso` | PHP (比索) | 目的港码头操作费(THC)及超期免堆期堆存费 |

## 📋 3. 散货/包裹级费用明细（散货应收应付 - `WaybillFee`）

散货/拼箱（LCL）与空运（AIR）按单票运单计费：

| 计费项目 | 海运散货 (SEA_LCL) 计费规则 | 空运 (AIR) 计费规则 |
| :--- | :--- | :--- |
| **计费单位** | 立方米 ($\text{CBM}$) | 公斤 ($\text{kg}$) |
| **应收运费** | $\text{应收体积} \times \text{应收单价}$ | $\text{合计重量} \times \text{应收单价}$ |
| **应收比索 (PHP)** | 支持直接录入比索单价/总价（目的国现结） | 较少使用比索，主要人民币现结 |
| **应付干线成本** | $\text{应付体积} \times \text{应付单价}$ | $\text{合计重量} \times \text{应付单价}$ |
| **附加杂费明细** | 报关费（如 ¥500）、国内送仓提货车费等 | 内部车费（如 ¥99）、渠道车费（如 ¥93） |
| **一口价模式 (`isFixedPrice`)** | 勾选后直接以固定总金额锁定应收，覆盖体积单价 | 支持特货/样品一口价覆盖 |

## 🧮 4. 财务核算与对账公式总结

1. **整柜毛利公式 (FCL)**:
   $$\text{整柜毛利 (RMB)} = \text{客户整柜报价} - \sum (\text{订舱费折算} + \text{港杂} + \text{头程拖车} + \text{报关费} + \text{清关费} + \text{THC折算} + \text{目的港拖车} + \text{小费折算})$$

2. **拼箱柜汇总毛利公式 (LCL Consolidated)**:
   $$\text{拼箱柜汇总毛利} = \sum_{\text{该柜所有散货}} \text{散货应收} - \sum \text{集装箱实际发生干线硬成本}$$

3. **单票散货毛利公式 (Waybill Margin)**:
   $$\text{运单纯毛利} = \text{总应收金额 (receivableAmount)} - \text{总应付成本 (payableAmount)}$$

4. **汇率折算机制 (`exchangeRate`)**:
   - 系统支持为外币记录自定义汇率（如 $1\text{ USD} = 7.20\text{ CNY}$， $1\text{ CNY} = 8.00\text{ PHP}$）；
   - 系统在写入 `amount` 的同时自动换算并持久化缓存 `amountInCny`，确保财务总账报表币种统一。
