## 🛠️ 3. 渠道与服务商分类规范 (`ShippingChannel`)

### 3.1 渠道架构设计核心认知
在国际物流运作中，渠道服务商的对接模式按**货运方式与物流分段**存在根本差异：
- **海运拼箱 (`SEA_LCL`) & 空运专线 (`AIR`)**：属于端到端的专线承运服务商（如自营专线、庄家专线），全链路负责或整体外发；
- **海运整柜 (`SEA_FCL`)**：属于分段专业协作链路，涵盖 **订舱、报关、清关、拖车** 4 类完全独立的服务商实体；
- 💡 **关键避坑**：“报关通道（普货/特货/退税等货品申报属性）”与“报关渠道（出口报关行实体）”概念截然不同，系统严禁将渠道商与货品属性强行级联绑定。

### 3.2 6 大渠道业务分类与服务商标杆字典

| 分类代码 (`ChannelCategory`) | 中文分类名称 | 适用业务场景与角色 | 常见代表服务商 / 示例 |
| :--- | :--- | :--- | :--- |
| `SEA_LCL` | **海运拼箱专线** | 散货拼箱干线与境外派送承运商 | **万海自营拼箱专线** (默认)、中外运拼箱、天帆东南亚散拼、同行外发分拨 |
| `AIR` | **空运专线渠道** | 航空特快专线 / 航司一级庄家 | **菲通货运专线** (默认)、万海特快航空 |
| `FCL_BOOKING` | **整柜 - 订舱渠道** | 船司直订或一级海运订舱代理 | **优尼科订舱** (默认)、泉州万海订舱部、中远海运(COSCO)直订 |
| `FCL_CUSTOMS` | **整柜 - 报关渠道** | 国内起运港正规出口报关行 | **中外运报关行** (默认)、报关资料群(快通) |
| `FCL_CLEARANCE` | **整柜 - 清关渠道** | 目的港专业清关代理行 | **菲立亚清关公司** (默认)、天帆目的港清关 |
| `FCL_TRUCKING` | **整柜 - 拖车渠道** | 码头港口集卡拖车与内陆驳运车队 | **厦门联运车队** (默认)、优尼科港口集卡 |

### 3.3 渠道后台管理与工作台默认预选机制
1. **后台独立集中维护 (`/v2/channels`)**：支持对各分类下的服务商进行增删改查、联系方式登记、启用/停用控制；
2. **默认推荐标记 (`isDefault`)**：每个分类支持设置 1 个默认推荐服务商，业务员在录单或调度时系统自动预选填入，大幅提升录单流转速度。

## 📦 5. 状态流转与标准枚举映射

| 业务状态 | 运单状态代码 (`WaybillStatus`) | 集装箱状态代码 (`ContainerStatus`) | 中文名称 | 触发条件 / 业务动作 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 预报中 / 待入库** | `DRAFT` | (无) | 客户委托预报 | 客户下单，生成系统运单号，货物尚未到仓 |
| **2. 待装柜 / 已入库** | `INBOUND` | (无) | 仓库实测核量 | 仓库收到包裹，测出长宽高体积与重量，生成主运费 |
| **3. 已装柜 / 配载** | `LOADED` | `LOADING` | 已拼箱装柜 | 业务员将多票散货关联到集装箱柜号 (containerId) |
| **4. 在途 / 已开船** | `IN_TRANSIT` | `SAILING` | 国际干线运输中 | 对应集装箱上船开航 (ETD) 或空运航班起飞 |
| **5. 目的港清关** | `CUSTOMS` | `CUSTOMS` | 目的港海关申报 | 船舶到达清关港口，清关行报关递单 |
